## Immersive Experience

Saurabh added features where the user can officially interact with the scene. Using Trigger buttons to execute various modes such 
as “Listen” (RT0), “Execute” (RT1), “Clear” (LT0), and “Help” (LT1).

Saurabh added some features in the Immersive VR mode, which helps create a more welcoming environment for the user, as below:

- Added a feature, where instead of headlocked UI Panels that invade the user’s space, they are now locked onto the left and right wrists. 
Example: pressing the Right Trigger-1 (T0), will enter into the “Listen Mode”. When that happens, the user may glance at their wrists to trigger the UI Panels

- Glancing away from the wrists will make the UI Panels disappear gracefully, giving the user a choice to check out info any time they want.

- The Help Screen is a small friendly UI Panel on the left Wrist. All the info about “Listen”, “Execute”, and “Clear” still exists in the UI Panel on the right wrists

Saurabh also added a “Haptic” Feedback, where the controller vibrates in accordance with what the user is pressing at the time. Example, long pressing RT1, is 
“Execute” mode. Then Haptic feedback will pulse thrice: low at trigger time, medium at 50% and high pulse at 100%, giving a sense of constant feedback without having 
to glance at the wrists.

## Potential Improvement

**Saurabh proposed a helper feature: A controller system where the user maybe able to “walk” inside the immersive VR mode, without having to physically walk inside 
the real world.**

- Saurabh believes that the user must have full control over the scene. That includes locomotion, rotation, and must assume that the user is unable to do so in real 
life. This maximizes empathy for the User Study Volunteers, ensuring a smooth, comfortable, and unbiased experience.

- For that, we can use simple Joystick based locomotion. Instead of VR Fatigue and Nausea inducing fast paced control systems, we can have a simple “snap” mechanism, 
which can help the user slowly locate themselves without physically walking over to the place.

This requires a third person to give some comments on this part of the feature design, as there is no gurantteed answer to this proposal.
